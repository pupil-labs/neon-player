- Fixes export of fixations mapped to a tracked surface: the `fixation x/y [normalized]` columns now contain average x/y coordinates of all mapped gaze samples that belong to a fixation
- Adds a context menu option to set an event as one of the boundaries of the export window (accessible by right-clicking on the respective event in timeline)
- Adds key bindings for increasing (Shift+.) and decreasing (Shift+,) playback speed
- Changes playback speed options from [0.25x, 0.5x, 0.75x, 1x, 1.25x, 1.5x, 1.75x, 2x] to [0.125x, 0.25x, 0.5x, 1x, 2x, 4x]
- Adds dedicated functions for retrieving and changing the current export window within a custom plugin (accessible via `self.app.get_export_window` and `self.app.set_export_window`)
