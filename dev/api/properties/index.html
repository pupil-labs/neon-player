    add_button_text class-attribute instance-attribute ¶

    add_button_text: str | None = None

    For list properties, sets custom text to the button for adding elements.

    By default (None), the text is generated automatically depending on the type of elements stored in the list. For simple types (str, int, float, bool), "Add value" is displayed. For other types, "Add {type.__name__}".

    allow_none class-attribute instance-attribute ¶

    allow_none: bool = False

    For type properties, sets if None is included as one of the options.

    auto_expand class-attribute instance-attribute ¶

    auto_expand: bool = False

    For list properties, controls whether list elements are expanded by default.

    This parameter should be passed within the item_params dictionary. In addition, it only applies if the list elements have a custom type that contains one or more properties. In that case, each element is rendered as a collapsible form with one or more widget, and auto_expand=True make the form expand by default (e.g., when new elements are added).

    base_class class-attribute instance-attribute ¶

    base_class: type | None = None

    For type properties, sets the custom base class.

    The corresponding subclass selector widget will display all subclasses of the provided base class as options.

    decimals class-attribute instance-attribute ¶

    decimals: int | None = None

    For float properties, sets the amount of decimals to display and use.

    dialog_title class-attribute instance-attribute ¶

    dialog_title: str | None = None

    For path properties, specifies the custom title of the opened file dialog.

    directory_mode class-attribute instance-attribute ¶

    directory_mode: bool = True

    For path properties, specifies whether directories or files are allowed.

    By default, properties that return pathlib.Path only accept directories, while properties that return FilePath only accept files.

    dont_encode class-attribute instance-attribute ¶

    dont_encode: bool = False

    Controls whether the property value is stored in the JSON state.

    file_filter class-attribute instance-attribute ¶

    file_filter: str | None = None

    For file-path properties, restricts the type of files that can be opened.

    The expected filter format is described in the Qt documentation. Using the filter, it is possible to allow opening, for example, only images or only files with a specific extension.

    item_params class-attribute instance-attribute ¶

    item_params: dict | None = None

    For list properties, allows passing parameters that apply to list elements.

    In particular, label_field and auto_expand parameters should only be passed within this dictionary.

    label class-attribute instance-attribute ¶

    label: str | None = None

    The display name of the property.

    If None (default), the display name is generated automatically from the property name by replacing all underscores with spaces and applying capitalization.

    label_field class-attribute instance-attribute ¶

    label_field: str = '__name__'

    For list properties, sets the display name of list elements.

    This parameter should be passed within the item_params dictionary.

    label_lookup class-attribute instance-attribute ¶

    label_lookup: Callable[[str], str] | None = None

    For dict properties, defines the display name of each dictionary key.

    If None (default), each key will be shown as is. Otherwise, a callable that return the display name for each key should be provided.

    max class-attribute instance-attribute ¶

    max: int | float | None = None

    For int/float properties, sets the maximum allowed value.

    max_length class-attribute instance-attribute ¶

    max_length: int | None = None

    For string properties, restrict the maximum allowed string length.

    min class-attribute instance-attribute ¶

    min: int | float | None = None

    For int/float properties, sets the minimum allowed value.

    none_label class-attribute instance-attribute ¶

    none_label: str | None = None

    For type properties, sets the display label for the None option.

    options_changed_signal class-attribute instance-attribute ¶

    options_changed_signal: Optional[str] | None = None

    Signal that implies that the list of drop-down options has changed.

    Every time the signal is emitted, the options for the drop-down widget are re-evaluated based on the value obtained from options_source.

    options_source class-attribute instance-attribute ¶

    options_source: Iterable[Any] | Callable[..., Iterable[Any]] | str | None = None

    Provides a list of options to be used in a dynamic drop-down widget.

    The following objects are accepted as the source of options: - Name of a field that belongs to the same class as the property and stores the options for the property widget - An Iterable value that contains the options for the drop-down widget, or a callable that returns such a value - None (default) corresponds to the empty list of options

    prevent_add class-attribute instance-attribute ¶

    prevent_add: bool = False

    For list properties, controls whether the button for adding elements is shown.

    By default (False), the button is shown. Pass True to hide the button.

    primary class-attribute instance-attribute ¶

    primary: bool = False

    Controls whether the display name of the property is shown.

    Set to True to hide the property name and show only its value in the form.

    show_slider class-attribute instance-attribute ¶

    show_slider: bool | None = None

    For int/float properties, explicitly shows or hides the slider widget.

    By default, the slider is shown if min and max parameters are specified.

    show_spinbox class-attribute instance-attribute ¶

    show_spinbox: bool = True

    For int/float properties, explicitly shows or hides the spinbox widget.

    By default, the spinbox is always shown.

    step class-attribute instance-attribute ¶

    step: int | float | None = None

    For int/float properties, sets the step of the slider and spinbox.

    use_subclass_selector class-attribute instance-attribute ¶

    use_subclass_selector: bool = False

    For list properties, allows selecting a subclass for newly added elements.

    By default (False), all added elements will have the same type T as specified in the type hint of the property: list[T]. If set to True and type T has several subclasses, a drop-down with all known subclasses of T will be shown, and the selected type will be used for the new element instead.

    visibility_changed_signal class-attribute instance-attribute ¶

    visibility_changed_signal: SignalInstance | None = None

    Signal that implies that the visibility of the property has changed.

    Every time the signal is emitted, the visibility of the property widget is re-evaluated based on the value obtained from visibility_source.

    visibility_source class-attribute instance-attribute ¶

    visibility_source: str | Callable[..., SupportsBool] | SupportsBool | None = None

    Controls the visibility of the property widget.

    The following options can be passed as the source of visibility status, with returned value always being coerced to bool:

    • Name of a field that belongs to the same class as the property and stores the visibility status of the property widget
    • A bool value that sets the visibility status of the property widget, or a callable that returns such a value
    • None (default) makes the property widget always visible

    widget class-attribute instance-attribute ¶

    widget: QWidget | None | Literal['auto'] = 'auto'

    The widget to use for this property.

    If None, the property will not be displayed in the UI. Provide a subclass of QWidget to set the desired widget explicitly. By default, the widget will be selected automatically based on the type hint of the value that the property returns.
